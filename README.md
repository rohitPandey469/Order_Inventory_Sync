# Mars Cosmetics — Order & Inventory Sync Service

A design proposal for a centralized order and inventory synchronization service connecting the company website, Nykaa, Flipkart, Blinkit, and Microsoft Business Central.

The proposed architecture uses NestJS, PostgreSQL, Redis, and AWS SQS to support atomic inventory reservations, asynchronous stock synchronization, and reliable ERP delivery.
